# The Coda Book

## Introduction

Hello!

If you're reading this book, you're probably looking for a programming language that gives you complete control over your software, without forcing you to fight unnecessary complexity.

Coda is a statically typed systems programming language designed around explicitness, predictable performance, and compile-time programming. It is intended for everything, from command-line utilities to operating systems, game engines, compilers, and embedded software.

This book will teach you the language from first principles. No previous experience with Coda is needed!

## About This Book

The Coda Book is a tutorial for learning the Coda programming language.

It is written to introduce Coda gradually, starting with the fundamentals and building towards more advanced features. Each chapter introduces a small number of concepts, explains how they work, and uses them in practical examples.

Coda is still under development, and the languaage may change as it evolves. This book describes the current version of Coda and may be updated alongside it.

The examples in this book are intended to be used, not just read. Try changing them, breaking them, and writing your own programs. Experimenting with the compiler is often the best way to understand how Coda works!
