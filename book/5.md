# Chapter 5 - Control Flow

So far, every program you've written has executed one statement after another.

Real programs are rarely so simple.

Sometimes you only want to execute code when a condition is true. Other times you want to repeat the same operation many times.

Control flow determines which parts of a program are executed and in what order.

---

## Blocks

A block is a group of statements enclosed by braces.

```coda
{
    dbg::println("Hello");
    dbg::println("World");
}
```

Statements inside a block execute from top to bottom.

Blocks also define a new scope for variables, a concept you'll explore later in this chapter.

---

## Conditional Execution

The `if` statement executes a block only when its condition evaluates to `true`.

```coda
int32 age = 18;

if (age >= 18) {
    dbg::println("Adult");
}
```

If the condition is `false`, the block is skipped.

Conditions must have the type `bool`.

Unlike some languages, integers are **not** implicitly converted into boolean values.

The following does not compile:

```coda
int32 value = 42;

if (value) {
}
```

Instead, write an explicit comparison.

```coda
if (value != 0) {
}
```

Being explicit makes the programmer's intent clear.

---

## The `else` Statement

Sometimes there are two possible paths.

The `else` clause executes when the `if` condition is false.

```coda
int32 temperature = 12;

if (temperature >= 20) {
    dbg::println("Warm");
} else {
    dbg::println("Cold");
}
```

Only one branch is executed.

---

## Chaining Conditions

Multiple conditions may be tested using `else if`.

```coda
int32 score = 82;

if (score >= 90) {
    dbg::println("Excellent");
} else if (score >= 75) {
    dbg::println("Good");
} else if (score >= 50) {
    dbg::println("Pass");
} else {
    dbg::println("Fail");
}
```

Conditions are evaluated from top to bottom until one succeeds.

---

## While Loops

A `while` loop repeats a block while its condition remains true.

```coda
mut int32 count = 0;

while (count < 5) {
    dbg::println(count);
    count += 1;
}
```

The condition is checked before every iteration.

If it is initially `false`, the loop body is never executed.

---

## For Loops

When iterating over a range or collection, a `for` loop is often clearer.

```coda
for (mut int32 i = 0; i < 5; i += 1) {
    dbg::println(i);
}
```

This example consists of three parts:

* an initialiser,
* a condition, and
* an update expression.

The initialiser runs once.

The condition is checked before each iteration.

The update expression runs after every iteration.

---

## Breaking Out of a Loop

The `break` statement immediately exits the nearest enclosing loop.

```coda
mut int32 i = 0;

while (true) {
    if (i == 10) {
        break;
    }

    dbg::println(i);
    i += 1;
}
```

Execution continues with the first statement following the loop.

---

## Continuing a Loop

The `continue` statement skips the remainder of the current iteration and begins the next one.

```coda
for (mut int32 i = 0; i < 10; i += 1) {
    if (i % 2 == 0) {
        continue;
    }

    dbg::println(i);
}
```

This program prints only the odd numbers.

---

## Variable Scope

Variables only exist within the block in which they are declared.

```coda
{
    int32 number = 42;
}

dbg::println(number);
```

This does not compile because `number` no longer exists after the block ends.

Limiting the lifetime of variables helps keep programs easier to understand.

---

## Putting It Together

The following program repeatedly counts down before printing a final message.

```coda
module countdown;

include std::debug = dbg;

@entry
fn none main() {
    for (mut int32 i = 5; i > 0; i -= 1) {
        dbg::println(i);
    }

    dbg::println("Lift off!");
}
```

Although simple, this program demonstrates variables, expressions, loops, and conditional execution working together.

---

## Experimenting

Try making the following changes:

* Count upwards instead of downwards.
* Change the loop to print the numbers from 1 to 100.
* Add an `if` statement that prints only even numbers.
* Replace the `for` loop with an equivalent `while` loop.
* Use `break` to stop the loop early.

Experimenting is one of the best ways to understand how control flow works.
