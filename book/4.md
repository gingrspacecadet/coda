# Chapter 4 - Expressions and Operators

In the previous chapter, you learned how to store values in variables.

Now it's time to do something with those values.

An **expression** is any piece of code that produces a value.

Some expressions are as simple as a single number.

```coda
42
```

Others combine several values to produce a new one.

```coda
5 + 3
```

Understanding expressions is fundamental to writing Coda programs.

---

## Literals

A literal is a value written directly into the source code.

Examples include:

```coda
123
```

```coda
true
```

```coda
'A'
```

```coda
"Hello!"
```

Each literal has a type determined by its form.

---

## Arithmetic Operators

Coda provides the familiar arithmetic operators.

```coda
+
-
*
/
%
```

For example:

```coda
int32 a = 12;
int32 b = 4;

dbg::println(a + b);
dbg::println(a - b);
dbg::println(a * b);
dbg::println(a / b);
dbg::println(a % b);
```

These operators behave exactly as their mathematical counterparts.

---

## Assignment

The assignment operator stores a value into a mutable variable.

```coda
mut int32 score = 0;

score = 10;
```

The left-hand side must be mutable.

Attempting to assign to an immutable variable is a compile-time error.

---

## Compound Assignment

A common pattern is to assign the result of an operation back to the same variable.

Instead of writing:

```coda
count = count + 1;
```

Coda provides compound assignment operators:

```coda
count += 1;
count -= 1;
count *= 2;
count /= 2;
count %= 10;
```

These are simply shorthand for the corresponding assignment.

---

## Comparison Operators

Comparison operators produce a `bool`.

```coda
==
!=
<
<=
>
>=
```

For example:

```coda
int32 age = 18;

dbg::println(age >= 18);
```

The output is:

```text
true
```

---

## Logical Operators

Boolean values can be combined using logical operators.

```coda
&&
||
!
```

Example:

```coda
bool logged_in = true;
bool admin = false;

dbg::println(logged_in && admin);
```

---

## Bitwise Operators

Integer values also support bitwise operators.

```coda
&
|
^
~
<<
>>
```

These operate directly on the binary representation of the value.

They are commonly used in systems programming, networking, graphics, and embedded software.

---

## Operator Precedence

Expressions are evaluated according to precedence rules.

For example:

```coda
2 + 3 * 4
```

evaluates as:

```text
2 + (3 * 4)
```

because multiplication has a higher precedence than addition.

Parentheses can always be used to make evaluation order explicit.

```coda
(2 + 3) * 4
```

When in doubt, prefer parentheses.

They improve readability even when they are not strictly required.

---

## Putting It Together

```coda
module hello;

include std::debug = dbg;

@entry
fn none main() {
    mut int32 score = 10;

    score += 5;

    bool passed = score >= 15;

    dbg::println(score);
    dbg::println(passed);
}
```

This program demonstrates arithmetic, assignment, comparison, and logical expressions working together.
